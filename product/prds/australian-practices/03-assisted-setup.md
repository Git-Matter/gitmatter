# PRD 03: Assisted setup and trustworthy AI configuration

## Problem and outcome

Sole practitioners may not have dedicated IT staff. They need a clear setup path and enough information to decide whether a particular AI account and processing route is suitable for their work.

## First release

Provide an accessible setup checklist and practice preferences in Settings, link to the existing AI-account and agent connection controls, and make assisted onboarding discoverable from public pages. Reconcile retention and storage wording across the prominent marketing surfaces and setup documentation.

## Requirements

1. Explain the two existing execution paths: a connected external assistant under that assistant's account terms, or gitmatter's built-in features under the configured API-provider account.
2. Never imply a paid consumer subscription automatically establishes enterprise confidentiality or zero retention. Avoid provider retention durations that have not been verified against current terms.
3. Distinguish document object storage, account/database data, backups, monitoring, AI-provider processing, and external assistant handling. Do not infer governing law from storage region.
4. Provide links to choose AI settings, connect an agent, set practice preferences, and try fictional material. Each checklist item describes what the practitioner needs to verify; no unchecked contractual claim is presented as a technical guarantee.
5. Assisted-setup contact uses the established booking/contact destination and does not send a message without user action.
6. Never collect API credentials through pilot enquiry forms, mailto links, analytics, or support instructions.

## Acceptance

- Homepage, trust band, setup guidance, and relevant security text consistently qualify provider retention.
- A practitioner can reach all setup controls without navigating developer documentation.
- Practice preferences persist and tenant boundaries are enforced (PRD 04).
- No email, booking, API subscription, or provider agreement is silently created.
- Existing self-hosting and bring-your-own-agent paths remain available.

## Measurement and limits

Observe setup completion and assistance required in the pilot. Hosted geographic processing and provider contracts require operational evidence outside source code. Do not publish a residency or certification claim without that evidence.
